# Swipe Presentation Editor

A lightweight presentation editor with swipe slides, editable text boxes, and built-in gamepad controls for touch + keyboard use.

## Download Android APK

> After you build/export your Android app, place the APK at `downloads/presentation-editor.apk` in this repo.

- [⬇️ Download Latest APK](./downloads/presentation-editor.apk)

## Current Controls

- **Arrow Left/Right**: Previous/Next slide
- **Arrow Up/Down**: Move active textbox
- **Enter (A)**: Open formatting toolbar
- **Backspace (B)**: Clear selected textbox

## Notes

If the APK link shows 404, upload a fresh APK file to the `downloads/` folder and commit it.
